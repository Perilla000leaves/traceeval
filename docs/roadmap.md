# 路线图

按「先能用、再能比、最后能被引用」排。

## v0.1（当前）

- [x] 轨迹模型与三种匹配语义
- [x] 假成功检测（发出调用但没有返回）
- [x] 未判定与失败严格区分
- [x] OpenAI / Anthropic / 通用事件流三种适配
- [x] 用例集与轨迹集分离，支持离线回放
- [x] 报告：总览 + 失败归因 + 逐条明细 + 时延/成本分位

## v0.2 — 让评测更贴近真实失败

- [ ] **越界检测**：写操作工具被调用，但轨迹里没有对应的审批事件
- [ ] **副作用核验**：写操作后检查外部状态（可插拔 checker，默认空实现）
- [ ] 参数归一化策略可配置（日期相对化、ID 大小写、列表顺序无关）
- [ ] 轨迹 diff：同一用例两次运行的差异对比（回归定位）

## v0.3 — 公开基线

- [ ] 3 类任务的公开用例集：多跳检索 / 写操作审批 / 长任务续跑
- [ ] 收录 2–3 个开源 agent 的录制轨迹与基线报告
- [ ] 报告做成稳定的 JSON schema，便于别人聚合

## v0.4 — 接入层

- [ ] OTel GenAI 语义约定（span 属性）直读
- [ ] MCP tool call 日志直读
- [ ] GitHub Action：在 PR 上贴评测报告

## 不做

- 不跑模型、不做 prompt 调优建议、不做 LLM-as-judge（那类评测与轨迹判定是两件事）
